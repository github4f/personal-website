# Farshad Firouzi — Personal Website (V14)

A static, multi-page website built with HTML, CSS and JavaScript.

## Local preview
Open `index.html` in a browser, or run `python -m http.server 8000` in this folder and visit http://localhost:8000.

## GitHub Pages
Upload the contents of this folder to the root of a public GitHub repository. Under Settings → Pages, select Deploy from a branch, main, /(root).

## Pages
- index.html — homepage
- about.html — biography and leadership
- research.html — four research pillars and openings (#openings)
- innovation.html — four selected projects and initiatives
- contact.html — contact and external profiles

The Google Scholar, LinkedIn and O²-RAN URLs are maintained as external links. Light/dark mode saves the visitor’s preference locally.
